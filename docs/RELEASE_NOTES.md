## Итерация 3 — «Лучше ГдеБЕНЗ: карточка» · 2026-07-12

**Что появилось:** карточка АЗС уровня Uber. Статус по КАЖДОМУ виду
топлива («95 — Есть, 92 — Мало, ДТ — Нет») — вычисляется из свежих меток,
упоминающих топливо; ★-оценка достоверности (1–5 из согласованности
меток) в шапке карточки; факты отдельными строками: «Последнее
подтверждение · 3 мин назад», «Подтвердили · 18 за час», «Очередь ·
≈ 10–20 минут» (минуты вместо машин); быстрые действия в ОДИН тап —
«Нет бензина» и «Очередь» прямо с карточки, без открытия списка;
история — как чат: стабильные анонимные псевдонимы из deviceId
(«Екатерина · Есть топливо · 2 мин назад»), настоящих имён и
регистрации по-прежнему нет.

**Что изменилось:** дизайн-роль в AGENTS.md усилена до Digital Design
Director («интерфейс, которому завидуют дизайнеры»); координаты убраны
из карточки (техшум).

**Что удалено:** строка-свалка «подтверждено · метки · достоверность» —
разнесена по структурным строкам.

**Что стало быстрее:** частые исходы («нет бензина», «очередь») — 1 тап
вместо 2.

**Что стало проще:** ответ «какое топливо есть» виден построчно, без
чтения чипов.

**Design Review (почему этот экран выиграл бы Awwwards):** карточка
отвечает на все вопросы водителя сверху вниз без единого лишнего
элемента — статус → топливо построчно → доверие цифрами → действие;
иерархия как у Flighty: одна эмоция на блок, один зелёный CTA, факты
таблицей с воздухом. Слабое место — пока нет микроанимаций появления
блоков; кандидат на следующий 20%-слот полировки.

**Изменение SFS:** решение «ехать/не ехать» принимается по конкретному
топливу, а не по общему статусу — меньше пустых поездок.

**Риски:** пофьюельный статус — эвристика по упоминаниям в метках
(до пофьюельной формы отметки в итерации «Оставил отметку 2.0»);
псевдонимы могут совпадать у разных устройств (это ок — они анонимны).

## Итерация 2.2 — «Приложение на главном экране» · 2026-07-11

**Что появилось:** PWA-установка. Манифест (standalone, start_url /map),
иконки, сгенерированные собственным PNG-энкодером без зависимостей
(зелёный пин, обычная + maskable + apple-touch). Умный мастер: Android/
desktop Chrome — системный prompt через beforeinstallprompt; Android без
prompt — шаги «⋮ → Добавить на главный экран»; iPhone Safari — 3 шага
«Поделиться → На экран “Домой” → Добавить»; встроенные браузеры
(Telegram/MAX) — подсказка открыть в Safari. Кнопка «Установить» в шапке
карты (исчезает после установки). Авто-показ только после вовлечения:
2 карточки, метка или 45 сек на карте; закрыл — не показываем 30 дней;
первый запуск из иконки — разовое «Спасибо ❤️ Теперь “Тут Бензин” всегда
под рукой».

**Что изменилось:** карточка станции и метка шлют сигнал вовлечения.

**Что удалено:** ничего.

**Что стало быстрее:** возврат в сервис — одно касание с главного экрана.

**Что стало проще:** установка — по кнопке, сценарий свой для каждой
платформы, без непонятных шагов.

**Что осталось сделать:** service worker для офлайна (BACKLOG);
скриншоты в манифест; аналитика конверсии установки.

**Изменение SFS:** прямого нет; retention — иконка на главном экране
возвращает чаще, чем вкладка.

**Риски:** определение встроенных браузеров по UA эвристично; iOS может
менять формулировки меню.

## Итерация 2.1 — «Пользоваться каждый день» · 2026-07-11

**Что появилось:** кнопка «Ближайшие с топливом» — список 12 ближайших
работающих АЗС от геопозиции (или центра карты): расстояние · сеть ·
статус · свежесть, тап открывает карточку; пульс-ореол станций, у которых
сменился статус при минутном обновлении; история в карточке стала лентой

закончилось», «Выросла очередь») и линией таймлайна; «обновлено N мин
назад» тикает само каждые 30 сек.

**Что изменилось:** импорт OSM перебирает зеркала Overpass по списку
(Mail.ru → overpass-api.de → kumi); архитектура подтверждена: Overpass
только в скрипте импорта, пользователи всегда читают из Postgres.

**Что удалено:** ничего.

**Что стало быстрее:** ответ «куда ехать» — одна кнопка вместо
разглядывания карты.

**Что стало проще:** история читается как лента событий, а не таблица
статусов.

**Что осталось сделать:** живой визуальный прогон (панель браузера
скрыта — среда замораживает WebGL); Lighthouse.

**Изменение SFS:** «Ближайшие» — кратчайший путь к успешному поиску
топлива; пульс покажет изменившуюся ситуацию без перезагрузки.

**Риски:** расстояние по прямой, не по дорогам (для маршрута — кнопка
навигатора в BACKLOG).

## Итерация 2 — «Карта должна стать полноценной» · 2026-07-11

**Что появилось:** ВСЕ АЗС 10 городов из OpenStreetMap — 2352 станции
(Москва 886, СПб 480, Казань 187, Ростов 182, Краснодар 168, Воронеж 169,
Симферополь 94, Севастополь 81, Астрахань 73, Сочи 32), импорт
идемпотентен (npm run import:osm, upsert по osmId); кластеризация
(клик — раскрытие зумом), невидимая зона тапа 20px у каждой точки;
полная карточка: название, сеть, адрес, координаты, топливо, свежесть,
очередь, «подтверждено N за час», достоверность %, история отметок
(таймлайн «Водитель · N мин назад · статус · детали»); живая карта —
опрос раз в 60 сек; поиск: город/сеть/адрес/станция; автоопределение
города по геолокации при первом входе.

**Что изменилось:** демо-метки теперь ложатся поверх реальных станций
(~60%, по тяжести региона), сид не создаёт станций; DoD Journey 1
ужесточён до паритета с ГдеБЕНЗ (USER_JOURNEYS.md).

**Что удалено:** выдуманные сидом станции (117) — данные теперь честные.

**Что стало быстрее:** рендер тысяч точек — GeoJSON-слои вместо DOM.

**Что стало проще:** «Здесь нет заправки» больше не нужно — станции
реальные из OSM.

**Что осталось сделать:** живая визуальная проверка чек-листа DoD
(панель браузера была скрыта — WebGL заморожен средой); Lighthouse;
комментарии свободным текстом (BACKLOG).

**Изменение SFS:** город целиком на карте → выше шанс найти заправку;
история + подтверждения → выше доверие решению «ехать/не ехать».

**Риски:** зеркало Overpass (Mail.ru) — внешняя зависимость импорта;
демо-метки на реальных станциях могут вводить в заблуждение до запуска
реального трафика (обязательно переседировать перед публикацией);
названия/бренды из OSM неидеально нормализованы.

## Итерация 1 — «Нашёл бензин» · 2026-07-11

**Что появилось:** карта Москвы на весь экран (MapLibre + CARTO, светлая и
тёмная), 45 демо-АЗС с 291 меткой; пины с цветом статуса; фильтр топлива
92/95/98/100/ДТ; фильтр статусов Есть/Мало/Очередь/Нет/Закрыта (не
подходящие под фильтр станции приглушаются); карточка станции (сеть,
адрес, статус, очередь, «обновлено N мин назад», «M меток за 24 часа»);
«Подтвердить информацию» → 5 кнопок в один тап → «Спасибо! ❤️»;
POST /api/marks с анти-накруткой (deviceId, 10 мин); статус вычисляется
из потока меток (TTL 3 ч), не хранится полем.

**Что изменилось:** каркас create-next-app превращён в продукт; порт 3001.

**Что удалено:** ничего (Platform не тронут — ни одного файла).

**Что стало быстрее:** ответ на «где 95?» — два клика от открытия сайта:
фильтр приглушает всё лишнее мгновенно, без запроса к серверу.

**Что стало проще:** метка = 2 тапа от карточки (CTA → статус); уточнения
топлива/очереди отложены в итерацию 2, обязательный путь минимален.

**Что осталось сделать:** проход «100 000 пользователей — что раздражает»
и топ-3 фиксов до итерации 2; полировка мобильного ряда фильтров;
подтверждение должно наследовать топливо станции (сейчас метка без
уточнения топлива временно скрывает чипы топлива на карточке).

**Изменение SFS:** сценарий Journey 1 проходится за ~15 секунд (DoD: 60);
карта отдаёт первый экран < 2 с локально; подтверждение обновляет статус
и «обновлено только что» мгновенно для отправителя.

**Риски:** демо-данные (адреса не совпадают с координатами — сид);
CARTO-тайлы — внешняя зависимость без ключа; фильтр топлива опирается на
fuelTypes последней метки — пустая метка не фильтрует станцию (осознанно).
